# Restaurant Managing System

The program "restaurant_managing_system.py" is a simple restaurant manager with various functions. To use these functions, the "food.csv" file, which represents the menu, is required. When running the program, the user can choose between six actions:

1. The menu is loaded from the "food.csv" file.
2. Place an order: The user is prompted for a table number and can order a dish from the menu for that table with an optional special request.
3. Cancel an order: First, the user is prompted for the table number where they want to cancel the dish. Subsequently, they are asked for the product they wish to cancel.
4. An invoice for a selected table is generated as a `.txt` file.
5. All tables and the number of their respective orders are displayed.
6. The program is terminated.

## Requirements & Execution
* A Python interpreter version 3.10 or newer with standard libraries and support programs from www.python.org must be installed.
* Start the program "restaurant_managing_system.py" in the usual manner for the respective operating system, from the interpreter shell or in an IDE, e.g., IDLE.

## Additional Notes
* No bugs are known.
